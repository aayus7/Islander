Islander 0.9.5 — a Dynamic Island for Windows
==============================================

INSTALL
1. Run "Islander_0.9.5_x64-setup.exe".
   (Windows may say "Windows protected your PC" because the installer isn't
   code-signed yet: click "More info" → "Run anyway".)
2. Islander starts right away and opens automatically when you sign in.
   Right-click the island → Settings to change anything.

FIRST-RUN PERMISSIONS (one time each)
- Notifications: Windows asks to let Islander read notifications → Allow.
- Wi-Fi network names: Settings → Privacy & security → Location →
  turn on "Let desktop apps access your location" (Windows requires this to
  list Wi-Fi networks; Islander never uses your location).

BROWSER EXTENSION (YouTube / web players / downloads in the island)
  The Islander Media Bridge extension is on its way to the Chrome Web Store and
  Firefox Add-ons. Until then, Spotify, media players and other Windows apps
  already show up in the island without it.

SHORTCUTS
- Ctrl+Alt+D       hide / show the island
- Ctrl+Alt+Space   Search or Ask (AI) — change in Settings if another app uses it

NOTES
- While Islander runs, it replaces Windows' volume pop-up and notification
  banners with its own. Quitting (right-click → Quit Islander) or uninstalling
  gives Windows its own back.
- The AI tab works out of the box. You can add your own Gemini API key in Settings → AI.
- Uninstall from Settings → Apps → Installed apps → Islander.
